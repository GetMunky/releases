# MUNKY downloads

**Our mission: revolutionize how everyday people experience the internet.**

MUNKY is being built as a free, ambient internet environment connecting real websites, understanding,
exploration, creation, collaboration, authorized actions, and continuity. Availability of individual
capabilities depends on the released version; this description is not a claim of universal autonomy.

This repository distributes public installation files, version metadata, and SHA-256 checksums.
Product source is maintained separately. A source commit, candidate build, signed binary, notarized
release, and installed application are distinct; consult the actual release's availability and notes.
Published versioned files are immutable. This documentation update changes no installer or release feed.

Download available MUNKY releases from [munky.sh](https://munky.sh/get-started/).
